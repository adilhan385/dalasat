> **DalaSat** — интеллектуальный сервис на базе спутниковых данных **Sentinel-2 L2A** и **Google Gemini AI** в Telegram для аграриев Акмолинской области. Мгновенная оценка биомассы (NDVI), влажности (NDMI), готовности почвы к севу, детекция построек (NDBI) и генерация юридически выверенного PDF-паспорта поля в 1 клик.

## 💡 Описание решения и решаемая проблема

Акмолинская область — зерновой пояс Казахстана (5.2 млн га пашни). Традиционный объезд полей занимает 3–5 дней, а суховеи иссушают пахотный слой за 48–72 часа. Зарубежные ГИС-системы (OneSoil, Cropwise) требуют дорогих валютных подписок ($1.5–$3/га) и сложны в освоении.

**DalaSat решает эту проблему:**
1. **Доступность в 1 клик:** Никаких установок приложений или сложных регистраций — работа прямо в Telegram со смартфона фермера.
2. **Мгновенный анализ (8–10 сек):** Технология **Cloud-Optimized GeoTIFF (COG) с windowed read** запрашивает у спутников Sentinel-2 только фрагмент поля (200 КБ вместо 800 МБ), что позволяет сервису летать даже при слабом 3G/LTE в поле.
3. **Двуязычный ИИ-агроном (Google Gemini):** Генерация практических рекомендаций на **казахском и русском** языках с учетом климатических условий Северного Казахстана (глубина заделки семян яровой пшеницы 5–6 см при иссушении, закрытие влаги боронами в 2 следа поперек ветров, стартовый аммофос).
4. **Официальный PDF-паспорт поля:** Векторный документ с картой вегетации и сводной таблицей метрик для агрономической отчетности и получения субсидий МСХ РК.

## 🛠 Технологический стек

* **Язык программирования:** Python 3.10 – 3.12 (полностью асинхронная архитектура)
* **Telegram Framework:** Aiogram 3.x
* **ДЗЗ и ГИС-обработка:** `pystac-client`, `planetary-computer`, `rasterio` (COG windowed reading), `shapely`
* **Матричные вычисления:** `numpy`
* **Генерация карт:** `matplotlib`, `pillow`
* **Искусственный интеллект:** Google Gemini Interactions API (`gemini-3.5-flash-lite` с автоматическим каскадным fallback-механизмом)
* **Генерация документов:** ReportLab PDF engine (векторные паспорта полей)

## 🚀 Пошаговая инструкция по локальному запуску

Члены экспертной комиссии могут воспроизвести проект за 1 минуту на любой чистой машине.

### 1. Клонирование репозитория
```bash
git clone https://github.com/adilhan385/dalasat.git
cd dalasat
```

### 2. Создание виртуального окружения
```bash
# Windows:
python -m venv .venv
.venv\Scripts\activate

# Linux / macOS:
python3 -m venv .venv
source .venv/bin/activate
```

### 3. Установка зависимостей
```bash
pip install --upgrade pip
pip install -r requirements.txt
```

### 4. Настройка переменных окружения
Создайте в корне файл `.env` (на основе шаблона `.env.example`):
```env
TELEGRAM_BOT_TOKEN=8800586784:AAH...ваш_токен_бота...
GEMINI_API_KEY=AIzaSy...ваш_ключ_gemini...
```
*(Спутниковые снимки Sentinel-2 работают из открытого каталога без необходимости ключа).*

### 5. Запуск сервиса
```bash
python bot.py
```

После запуска бот готов принимать геолокации и координаты (например, тестовые координаты поля в Зерендинском районе: `53.2514, 69.1845`).
